Subject: Get Text-Free Image

Detect every visible word in the image, regardless of language, including English, Arabic, Hindi, or any other script.

Role:
If any part of a word is visible—even a single letter, digit, punctuation mark, symbol, emoji, special character, diacritic, watermark text, handwritten stroke, or partially visible character—it must be completely removed. No portion of the original text or character may remain visible.

Completely cover each detected text region, then fully reconstruct it by inpainting using ONLY the surrounding original background pixels. The final restored area must perfectly match the original colors, textures, gradients, patterns, lighting, shadows, paper grain, and design. The temporary masking must never appear in the final image.

Rules:

1. Treat symbols, emojis, punctuation, mathematical symbols, currency symbols, bullets, icons that are part of text, and all other special characters exactly like normal text—they must also be completely removed and inpainted.

2. Do not modify any non-text visual elements such as logos, graphics, borders, tables, lines, icons (that are not part of text), photographs, decorative elements, or the document layout.

3. Never create, extend, redraw, continue, or invent any new line, border, table edge, pattern, texture, shadow, decorative element, or graphic. Use ONLY the surrounding original background information to reconstruct the removed regions.

4. Every removed text region MUST be completely inpainted before returning the image. Never return an image containing white patches, unfinished inpainting, blank areas, or restoration artifacts.

5. Before returning the final image, verify that no visible text fragment, white pixel, ghost text, newly generated visual element, or editing artifact remains. If any are found, continue restoring until none remain.

6. The final image must appear exactly as if no text had ever existed, with no remaining text fragments, white patches, blur, ghost text, unfinished inpainting, visible editing artifacts, or newly generated visual elements.
